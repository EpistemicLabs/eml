## EML v0.21.3

The cockpit gets its own plugins, starting with Worktrees, and opening a note no longer overwrites it. No schema change and no migration.

### Cockpit plugins

- **Settings › EML Plugins.** The views next to a session are now two groups in the pane's tab bar: the session's (Terminal, Chat) and the plugins (Brain, Note, Worktrees). Brain is always on; Note and Worktrees can be switched off for the whole cockpit. A plugin that is off leaves the tab bar, the "+" menus and the command palette, and a pane showing it moves to the brain. Notes stay in the brain either way.
- **Worktrees.** The project folder's git worktrees against the default branch, one line each: branch, changed files, commits ahead and behind, the sessions working there, their ports, last activity. Opened, a worktree shows its changed files and commits. Below, the other local ports: the command line with secrets blacked out, memory, uptime, and who started it (a session of this cockpit opens on click). Read-only; on Windows the port list is not available yet.

### Notes and the brain pane

- **Opening a note no longer overwrites it.** An editor could save before the note's content had loaded, and write an empty note or another note's content over the one just opened. A note is now saved only by an editor that loaded it.
- **The note pane switches notes.** "‹ All notes" in the note's header goes back to the picker.
- **The brain pane keeps its view.** Lens, reach and type filters stay with the pane across desk switches and reloads. A new brain pane opens on the timeline.

### Settings

- **Your name in every space.** Settings › Account showed your name from the active space's brain: "—" in a shared space, or a wrong name in a space with an old user row. The cockpit now keeps the name once, in its config, next to your handle; an existing cockpit takes it over from your brain at the first start.
- **Situational rules.** Settings › Agents shows the agent's situational rules below the always-on ones, each with its trigger. Both lists sort by the label they show.
- **Spaces.** The picked space's details, members, backups and delete section sit in one framed panel under the space tabs, as in Agents and Models.

### Terminal

- **Codex runs inline in its pane.** In its full-screen mode Codex captured every mouse event, so a Codex pane could neither scroll nor select text. It now starts with `--no-alt-screen`: scrolling, selecting and copy work as in a shell. Its input sits below the last output instead of at the bottom of the pane. Running Codex panes keep the old behaviour until they restart.
- The terminal scrollbar is thinner (6 px).

### Under the hood

- **Dependencies** updated, among them zod 4.6.7 and body-parser 2.4.0 (two denial-of-service advisories), React 19.3, the MCP SDK, vite 8 and vitest 5.
- **Sealing a large op for a shared space** no longer copies the payload through a JS array; a 16 MiB op seals in about 1 ms instead of 600 ms.
- CI: the Windows tests write their temp files to the runner's own drive and stay within their timeouts.
