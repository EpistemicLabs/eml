## EML v0.21.6

The cockpit gets an update channel: stay on stable releases, or opt in to the alpha pre-releases of the next version. No schema change and no migration in this release.

### What's new

- **Update channel:** Settings › About › Updates has a new Channel switch. Stable (the default) offers releases only, as before. Alpha (experimental) also offers the pre-releases of the next version.
- **Alpha moves your brain forward:** the alpha builds are v0.22 and come with the next brain schema. Once a cockpit updates to one, its brain can't go back to stable v0.21, and in a shared space all members need the same channel to keep syncing.

### Update channel

- **Stable stays as it was.** The updater asks GitHub for the latest release, which never includes a pre-release. A pre-release the updater found earlier is never offered on stable.
- **Alpha takes the highest version.** It looks at the newest releases, pre-releases included and drafts left out, and offers the highest by semver precedence (0.22.0-alpha.3 < 0.22.0-alpha.10 < 0.22.0).
- **Switching checks again.** `PUT /api/app-update/channel` saves the channel in `app/update.json`, forgets the release the other channel found and checks right away. `GET /api/app-update` reports the channel.
- **Skipping and going back keep working** across pre-releases, and the notes after an update include the pre-releases only on alpha.
- The version rules now live in one module, `cockpit/host/src/domain/app-version.ts`, with their own tests.
