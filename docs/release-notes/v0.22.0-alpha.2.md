## EML v0.22.0-alpha.2 (Experimental)

An experimental pre-release of the alpha line. Early builds for testing: things may break, and a shared space stays compatible only while every member runs the same alpha. Brain schema 22, as in alpha.1.

### What's new

- **The task system runs in every space.** The per-space switch is gone: every space, shared ones included, has tasks, the task board, the runner and cycles. In a shared space each member's cockpit runs the background work (starting delegated steps, carrying tasks into the new cycle) only for the tasks that member owns. The owner is the first assignee, else whoever wrote the task.
- **Qwen Code is back on macOS.** In alpha.1 it was missing from Settings › Models and the new-session menus, because a merge dropped it from the host's provider list.
