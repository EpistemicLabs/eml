## EML v0.22.0-alpha.1 (Experimental)

The first build of the alpha line: the work that is not in a stable release yet, for testing. Early builds: things may break, and a shared space stays compatible only while every member runs the same alpha. Offered only to cockpits on the Alpha (experimental) update channel. The brain format is unchanged (schema 21), so this build reads and writes the same brain as v0.21.5.

### What's new

- **Update channels:** Settings › About › Updates › Channel picks Stable (the default, releases only) or Alpha (experimental), which also offers the alpha pre-releases.
- **Task system:** every session in a space with the task system works on a task, with an owner and an agent delegate. The Inbox · Now · Plan task board shows whose turn each task is.
- **Task trees and split off:** the tasks card shows the task trees of the desk's sessions. A new topic can be split off from the chat onto a new or an existing task, and a drifted session can be sorted.
- **Tasks from the desk:** open an existing task from the desk; an opened task shows its related tasks, and its journal starts folded.
- **Plugins per space:** Settings › Plugins with plugin manifests, a registry and custom MCP plugins, written into each space's MCP config.
- **Gmail and sign-ins:** the Gmail plugin's MCP part on your own Google client, several sign-ins per space, a Workspace service-account key, and OAuth sign-ins for MCP servers.
- **Sessions:** restart a chat session in place, lift a session's limits with a restart, and a "Limited" badge after the pane title lists what is off.
- **Sidebar and look:** the sidebar carries the navigation and the top bar is gone; the whole cockpit is on design tokens v2; every banner can be dismissed.
